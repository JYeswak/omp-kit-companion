## Coverage limits and observed script defects

- Category D advertises top-level verbs but tests only whether subtree contains a space. A nested path such as subtree=lessons, name=add generates root `omp-kit create`; service/list generates root `omp-kit ls`. This does not exercise the intended nested route. The generated create alias remains excluded from execution.
- The known-verbs query excludes null subtree records, although these include actual top-level verbs. This can misjudge whether a root alias already exists.
- Category G requires a prefix of at least four characters, excluding common OMP_* and XDG_* variables. Only seven distinct env surfaces receive the sixteen generated perturbations; this is not all 37 inventory env surfaces.
- Category A emits root-only flag typos rather than preserving the declaring command path. Successful parser hints are evidence about root parsing, not evidence that each declaring route implements intent recovery.
- There are 345 distinct naive argv vectors across 2,151 rows. Env payloads can distinguish identical --version vectors, and separate surface IDs preserve traceability, but repeated root typos are not independent behavioral coverage.
- The generated input is not a fresh model's behavior. It is a deterministic perturbation corpus with source-grounded preserved savvy additions; naive and savvy perspectives are methodological labels, not independent human/agent observations.
