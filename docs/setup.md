# External tools setup

Every external tool the kit uses: whether it is required, what kit feature it
enables, how to install it on macOS and Linux, the command that verifies it,
and what the kit does when it is absent.

This table is test-pinned: `tests/cli/setup-tools.test.ts` fails when
`omp-kit doctor --scope dicklesworthstone --json` probes a tool with no row
here, so the two cannot drift. The doctor's probe list is the registry in
`src/diagnostics.ts` (`STACK_SOURCE`); the test reads the same list through
the doctor command.

| `bun` | required | Every test, gate and CLI runs on Bun | `curl -fsSL https://bun.sh/install \| bash` | `curl -fsSL https://bun.sh/install \| bash` | `bun --version` | Scripts refuse with named `Bun is required` errors; nothing runs |
