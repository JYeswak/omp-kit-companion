kit-save-guard detects edits that predate or exceed this session's hunk and prescribes a private-index save instead of a whole-file `git commit --only`. It composes sequential edits from observed file snapshots, accepts a candidate only when its Git tree or commit contains the final session hunk, and prompts for `candidate <sha> for <repo-relative path>` in a bead comment or Agent Mail message. Regression coverage includes the cfsios 188/27 fixture, repeated alpha-to-beta edits, an unreported foreign write, both receipt channels, and the wholly owned path.
