- Opt-in `imessage-bridge` service (IMSGCHIEF1): with `imsg` on PATH and `imessage.handle` set in `fleet-watch.json`, new iMessages from Joshua's handle are delivered to the lead seat as proven prompts (only the 1:1 chat ever matches; other senders are dropped and only counted by hash, restarts redeliver nothing). A failed delivery keeps the old cursor so the next tick retries it (at-least-once: a redelivered prompt is possible after a failure). `omp-kit imessage send` replies, `notify-blocked` pushes once per key, and the daily `imessage-brief` job sends one summary. Without `imsg` the run reports UNAVAILABLE and install stays untouched.
