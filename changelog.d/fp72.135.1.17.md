### Fixed
- The installer says what to do when `gh` cannot verify. A `gh` older than 2.69 has no `attestation verify --source-digest` (the Ubuntu 24.04 distro package is 2.45) and prints its whole usage; that read as `KIT_ATTESTATION_UNVERIFIED`, a verdict on the archive. It is now `KIT_ATTESTATION_VERIFIER_UNAVAILABLE` with the first line of gh's complaint and the remedy: install GitHub CLI 2.69 or newer from https://cli.github.com (it need not be logged in). A missing `gh` gets the same hint instead of a bare `No such file`. The README and `docs/setup.md` state the 2.69 floor and the official apt/dnf repository for Linux. Verified on the published 0.2.140: gh 2.69.0 and 2.68.1 verify and install, 2.67 lacks `--source-digest`.
