### Fixed
- The installer and the updater no longer need a logged-in `gh`. The tag lookup and the attestation-bundle fetch now ask the public GitHub API directly with the Python standard library (anonymous requests are allowed 60 an hour; `GH_TOKEN`/`GITHUB_TOKEN`, if exported, is sent to `api.github.com` only), instead of `gh api`, which refuses without `gh auth login`. `omp-kit update` and its scheduled poll fetch and verify through the same embedded installer, so the installer, the updater and the poll share one client and one fail-closed policy. Verification is unchanged: `gh attestation verify --bundle` still checks the signature, the release workflow, the source digest and the SLSA predicate offline, so `gh` must be installed but need not be logged in. An unreachable or rate-limited API refuses as `KIT_ATTESTATION_SOURCE_UNVERIFIED` or `KIT_ATTESTATION_BUNDLE_UNAVAILABLE` and says to check the network, not to log in; an API base other than `https://api.github.com` or a loopback `http://127.0.0.1:PORT` test fixture refuses as `KIT_ATTESTATION_API_UNTRUSTED`. The README install blocks and `docs/setup.md` drop `gh auth login`. The scheduled poll's latest-tag lookup (`gh release view`) still needs a login; it is the one remaining wall.
- A newcomer installs with one command: `curl -fsSL https://raw.githubusercontent.com/JYeswak/omp-kit-companion/main/installer/get.sh | sh`. `installer/get.sh` is a short fetcher (no arguments, no verification of its own): it resolves the newest tag from github.com's `releases/latest` redirect, downloads that tag's `install.sh` and `install.py` (never `main`'s), runs them, and prints the `PATH` line to add, so the installer's fail-closed Sigstore/SLSA verification still gates every byte. It refuses a latest tag that is not a plain `vX.Y.Z`, refuses an override that is neither HTTPS nor loopback, and leaves no temporary files. The README's two 18-line install blocks are replaced by that command (identical in both places, test-pinned), and the by-hand recipe and a table of the installer's refusals are in `docs/setup.md`.
