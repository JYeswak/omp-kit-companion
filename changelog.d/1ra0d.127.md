- Fleet policy verification now follows git to the nearest real repository: commands inside ovnfs checkouts and linked worktrees are judged under that repository's own opt-in instead of refused as unverifiable. A git verification failure retries once, then enforces the last verified policy for ten minutes; with nothing verified it still refuses.
- Shell write guards now follow the command's own `cd` into an existing directory, so `cd var/agent-tmp/w && echo hi > ../../out` resolves where the agent wrote (inside the repository) instead of refused as a home-root write. Real home-root and system-temp writes stay refused.
