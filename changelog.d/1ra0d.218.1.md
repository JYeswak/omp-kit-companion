### Fixed

- `scripts/fresh-gate.sh` now runs the pre-commit members (`scripts/check-staged-*.sh`: imports, fragments, regexploit, pysafe, tempsafe, kitlib, br-init, wallclock, readme, embed) over the candidate, as a `staged` phase that always runs. A handoff committed in an ovnfs checkout carries no hooks, so those members never ran on it: a test that ran `sh -c <variable>` reached main (`6e6440a0eb`) and failed both hosted ladder jobs on the pysafe ratchet. The phase builds a scratch repository with the base commit as `HEAD`, the candidate's tree as the staged index, and the pushing checkout's objects and release tags, so each member judges exactly the staged change a hook would; a refusal names the member and ends the gate `RED`. `omp-kit land --exact-parent` and the push gate inherit it, because both run the gate on the candidate. On real history the phase refuses `6e6440a0eb` on `check-staged-pysafe.sh` and passes five other recent commits.
