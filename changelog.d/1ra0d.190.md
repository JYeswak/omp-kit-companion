### Added
- The load-watch job file now carries the probe target for its Agent Mail restart check (AMWATCH2). `OMP_KIT_AM_PROBE_PROJECT=<absolute project path> OMP_KIT_AM_PROBE_AGENT=<registered agent> omp-kit service install load-watch --apply --yes` renders both into the launchd job file or systemd unit; a later install or update from a shell without them keeps the installed values, two empty values clear them, and a half-set pair, a relative path or an agent name that starts with `-` or is longer than 64 characters is refused `AM_PROBE_INVALID`. With them set the probe is the `am agents show` call every `br` write makes, which is the call that hangs when the server wedges.
