- `omp-kit test --full` and the update postcheck accept the ladder's `flywheel-invariants` stage; since it was added every GREEN ladder was rejected as a stage-order mismatch, so no release built from main could pass its own full test.
- omp-kit resolves OMP when the `omp` on PATH is a compiled standalone binary (e.g. `~/.local/bin/omp`): it uses the package of exactly the version that binary reports, from a later `omp` on PATH or bun's global install, and refuses any other version. The version probe runs from the launcher's directory, so trust-gated launchers answer inside untrusted projects.
