- `kit-update` now finishes a pending update receipt by itself when its recorded postimage verifies and a fresh live recheck passes (reconcile, plugin relink, services), retrying a receipt it cannot finish at most once per 30 minutes, instead of staying PENDING until someone runs `omp-kit update --reconcile`. The omp start probe's default 45 s deadline now grows with host load per CPU (up to 4 times), so a slow cold start no longer holds an update; an explicit `OMP_KIT_START_PROBE_DEADLINE_S` is used as given and a start that never finishes still holds.
