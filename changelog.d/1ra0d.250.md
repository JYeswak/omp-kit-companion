### Fixed
- Commits and pushes no longer hang when an ovnfs checkout stalls (STORAGEROOTNFS1). The Agent Mail storage-root hook used to `realpath` every archived project key, so one transient NFS stall blocked every commit fleet-wide; it now corroborates each archived key against the repository's own spellings with pure string comparison, verifies an installer-recorded archive binding without touching any foreign path, and refuses on ambiguity instead of guessing. Re-running `scripts/install-pre-commit-storage-root-gate.sh` records the binding (alias-registered projects are migrated with an operator-visible verification); a moved repository or missing archive refuses with a re-run remedy.
