- `skills/fleet-restart/scripts/sitrep.py`: a parsed fleet sitrep. Per agent pane it reports state, flags, MCP versions and the last kit-callback line; per repo it reports open, in-progress and ready beads, closes today, and main CI. Every value comes from tmux/process data, `br` JSON or `gh` JSON, and the output is a JSON receipt with a sha256. Counts closes from `br list --status closed` (the default list omits closed beads, so earlier close counts read 0) and splits callbacks on the last `; NEXT` (evidence may contain `;`). `--selftest` covers parse positives, rejects, wrapped pane lines, timed near-misses and a planted close count.
