- `skills/fleet-restart/scripts/sitrep.py`: a parsed fleet sitrep. Per agent pane it reports state, flags, MCP versions and the last kit-callback line. Per repo it reports open, in-progress and ready beads, closes today, and a CI verdict over every workflow run on main's current HEAD commit (`GREEN`, `RUNNING`, `FAILING` or `NO_RUNS_ON_HEAD`). Every value comes from tmux/process data, `br` JSON or `gh` JSON, and the output is a JSON receipt with a sha256. Counts closes from `br list --status closed` (the default list omits closed beads, so earlier close counts read 0). Does not take "the latest run" as main's state: on 2026-10-11 that run was a days-old failure in one repo and a Dependabot run in another, neither on HEAD. Splits callbacks on the last `; NEXT` (evidence may contain `;`). `--selftest` covers parse positives, rejects, wrapped pane lines, timed near-misses, a planted close count and five CI verdict cases.
