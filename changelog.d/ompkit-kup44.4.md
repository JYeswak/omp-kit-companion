Test runners can scrub suite environments, isolate HOME/XDG/Git config and set a Git ceiling; unsafe inherited Git/tracker authority fails before tests. The scrub (OMP_KIT_SUITE_HERMETIC_ENABLE=1) and, under it, the macOS write/network fence (OMP_KIT_SUITE_FENCE_ENABLE=1) are opt-in until the full suite passes under them: the full suite on the published batch failed 100 tests under the scrub, so suites run with the caller's environment as in 0.2.80. Both stay tested on every run.
