- Scratch writes sent as a codex-style `write` event carrying an edit patch (instead of a `content` field) are now judged on the bytes the patch writes: disposable scratch content is admitted, while canonical tracked-source copies, rerunnable scripts, and instruction/packet artifacts are still refused with the same reasons as any other write. A patch-carrying write whose bytes truly cannot be read is admitted with a one-line notice, exactly like an edit; a write naming no content and no patch stays refused.
