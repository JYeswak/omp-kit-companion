# README-NOTES

Facts from finished work that may change what `README.md` asserts. This file is a
log **on purpose**; `skill://readme-update` drains it into the README as
present-tense state and then truncates it back to this header.

Append one block per finished unit. Do not edit `README.md` directly at finish time.

Rules for the fields:

- `target-section` — an **existing** README heading. If nothing can absorb the fact,
  write `none` and say why; that is a decision, not a licence to add a heading.
- `state-now` — one present-tense sentence. No `added`, `fixed`, `changed`, `now`,
  `today`, `this session`. If the sentence cannot survive that constraint, the fact
  belongs in the commit message, not the README.
- `evidence` — a command that reproduces it, or `path:line`. Prose is not evidence.
- `readme-change` — `none`, or exactly what to alter in `target-section`.
